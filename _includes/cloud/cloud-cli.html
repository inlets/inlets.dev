Headless by design

Built for agents, scripts, and automation.

Every tunnel is a single command. Provision, list, and connect entirely from the CLI, so automation and AI agents can stand up a public endpoint on demand and tear it down when the job is done.

On demand
Create a tunnel the moment you need a link, without opening a dashboard.
Scriptable
Drive it from a shell script, an automation pipeline, or an agent skill.
Ephemeral
Spin endpoints up for a preview or a test, then remove them cleanly.
# Create a tunnel in an EU region
$ inlets-pro cloud create kotori --region cambs1

# List your tunnels and their URLs
$ inlets-pro cloud ls
kotori   cambs1   online   https://kotori.cambs1.tryinlets.dev

# Connect a local service and go live
$ inlets-pro cloud connect kotori --upstream http://127.0.0.1:8080
